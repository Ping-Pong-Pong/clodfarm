# TypePop City

A top-down HD pixel-art living town where one blob per MBTI type lives, strolls the plaza, visits neighbours, makes friends, and sleeps through the night. A demo on the road to the TypePop companion world.

**Live demo:** https://ping-pong-pong.github.io/clodfarm/city/

## Run it

Static hosting only — no backend, no build step:

```bash
cd city
python3 -m http.server 8000   # then open http://localhost:8000/
```

Or open `index.html` directly in a browser (sprites load from `assets/`).

## What it does

- **16 residents** — one per MBTI type, each with their pal name (Pip, Nova, Sunny…), signature color, nickname, treasured prop, and type-flavored one-liners.
- **A living town** — 16 houses ring a central plaza with a fountain; a park with a pond; dirt paths; trees, rocks, flower beds; a wooden type-code sign (e.g. `ENFP`) by every door.
- **Resident AI** — modes cycle `home → wander → visit → home`; at night everyone walks home and sleeps (Zzz included). Speech bubbles show moods and one-liners; name tags appear as you zoom in.
- **Friendships** — when two residents bump into each other, a sparkle bursts and the friendship counter in the HUD ticks up.
- **Day/night** — auto-cycles (~150s day / ~60s night) with a blue tint, lit windows, stars, and fireflies. The ☀️/🌙 dock button cycles Auto → Day → Night.
- **Camera** — drag to pan, wheel / pinch to zoom (snapped to whole device pixels), click a resident or house for an info card; Residents and Houses panels jump the camera anywhere.

## Sprites

`assets/` holds `blob_{type}_{open,happy,sleep}.png` and `house_{type}.png` (generated by a separate asset worker). If a PNG is missing, a `Pix`-drawn placeholder stands in automatically — and the moment a real PNG appears it takes over with zero code change.

## Tech notes

- Pre-rendered HD (2x) background on an offscreen canvas; sprites cached; DOM tags/bubbles only for in-view residents at readable zooms — 60fps-friendly on a modern phone.
- Respects `prefers-reduced-motion` (no walk bounce, sparkles, or firefly drift).
- Press Start 2P font by CodeMan38 (OFL, included as `fonts.ttf`).
